윤년 판별 프로그램
  실행 방법 : 년도를 입력한다.
  실행 결과 : 입력 받은 년도가 윤년이라면 1을 출력, 그렇지 않으면 0 출력

초를 시,분,초로 변환 프로그램
  실행 방법 : 초를 입력받는다.
  실행 결과 : 시간과 분과 초로 각각 변환하여 출력

합격 여부 판단 프로그램
  실행 방법 : 점수와 출석률을 입력받는다.
  실행 결과 : 점수가 60점 이상이고 출석률이 80% 이상이면 1을 출력, 그렇지 않은 경우 0을 출력

EXEC 권한 추가 프로그램
  실행 결과 : 7이 출력됨(printf가 있는 경우).

BMI 계산 프로그램
  실행 방법 : 키와 몸무게를 순서대로 입력한다(키 먼저).
  실행 결과 : 계산된 BMI 값이 소수점 셋째 자리에서 반올림 하여 소수점 이하 둘째 자리까지 출력

성적 가중 평균 프로그램
  실행 방법 : 중간고사 점수 기말고사 점수 과제 점수를 순서대로 입력한다.
  실행 결과 : 중간고사 점수 30% 기말고사 점수 40% 과제 점수 30%를 반영한 평균 점수가 출력
