윤년 판별
  실행 방법 : 년도를 입력한다.
  실행 결과 : 입력 받은 년도가 윤년이라면 "윤년입니다."를 출력, 그렇지 않으면 "평년입니다." 출력

초를 시,분,초로 변환
  실행 방법 : 초를 입력받는다.
  실행 결과 : 시간과 분과 초로 각각 변환하여 출력

합격 여부 판단
  실행 방법 : 점수와 출석률을 입력받는다.
  실행 결과 : 점수가 60점 이상이고 출석률이 80% 이상이면 1을 출력, 그렇지 않은 경우 0을 출력

EXEC 권한 추가
  실행 결과 : 7이 출력됨(printf가 있는 경우).

BMI 계산
  실행 방법 : 키와 몸무게를 순서대로 입력한다(키 먼저).
  실행 결과 : 계산된 BMI 값이 소수점 셋째 자리에서 반올림 하여 소수점 이하 둘째 자리까지 출력

성적 가중 평균
  실행 방법 : 중간고사 점수 기말고사 점수 과제 점수를 순서대로 입력한다.
  실행 결과 : 중간고사 점수 30% 기말고사 점수 40% 과제 점수 30%를 반영한 평균 점수가 출력

가위 바위 보
  실행 방법 : player1과 player2가 입력 가위(1),바위(2),보(3) 중 하나씩 입력한다.
  실행 결과 : player1과 player2의 가위바위보 결과를 출력한다.

HelloWorld
  실행 결과 : HelloWorld가 출력된다.

정수의 나눗셈
  실행 결과 : 정수형 변수 total에 입력된 값을 정수형 변수 size에 입력된 값으로 나누었을 때의 몫과 나머지를 출력한다.

금액을 화폐 단위로 분해
  실행 방법 : 금액을 입력한다.
  실행 결과 : 입력 받은 금액을 화폐 단위(10000, 1000, 100, 10)로 분해되어 출력된다.

해당 월의 일 수 출력
  실행 방법 : 월(1 ~ 12)을 입력한다.
  실행 결과 : 입력받은 월과 일 수를 출력한다.
  + 윤년 판별
      
      실행 방법 : 년도와 월을 입력한다.
      
      실행 결과 : 입력받은 년도와 월을 출력한다. 입력 받은 월이 2월일 경우 년도에 따라 윤년을 판별하여 29일 혹은 28일을 출력한다.

학년 출력
  실행 방법 : 학년을 입력한다.
  실행 결과 : 입력받은 숫자에 따라 학년을 출력한다. 입력받은 숫자가 1~3이 아닌 경우 "잘못된 값을 입력함"을 출력한다.
